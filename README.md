## About

I build backend systems that stay up under load and the tooling that proves they do.

Most of my production work has been in Java and Spring Boot on Kafka-backed microservices at Dell and Moogsoft: an in-house incident notification service, a JMeter performance platform used to characterize scalability limits, and a Java/Spring Boot version migration across 1,300+ repositories. Before software I was a mechanical design engineer at Northrop Grumman, then wrote safety-critical C++ under DO-178C certification there.

Right now I'm shipping **Orbit**, a real-time group video calling platform running in beta, and building depth in RAG pipelines, agentic systems, and MCP.

Currently open to backend and AI infrastructure roles.

<details open>
<summary><b>Orbit</b> — real-time group video calling, currently in beta</summary>

<br>

Timeboxed group calls on a configurable cadence. Rebuilt from a shut-down app that stranded its users, with reliability and configurability as the design constraints.

- **Stack:** PostgreSQL, Express, React, Node.js, TypeScript
- **Video:** Daily.co WebRTC, selected over Twilio Video and AWS Chime after evaluation
- **Scheduling:** BullMQ durable delayed jobs on Redis sorted sets, worker running as its own service
- **Auth:** Twilio SMS/OTP
- **Deploy:** Railway, Prisma with pinned `binaryTargets`, custom domain via Porkbun and Cloudflare
- **Status:** ~50 daily active users, infra under $50/month, growth almost entirely organic

[![TestFlight Beta](https://img.shields.io/badge/Join_the_Beta-0D96F6?style=for-the-badge&logo=apple&logoColor=white)](https://apps.apple.com/us/app/testflight/id899247664)

</details>

<details>
<summary><b>California Culinary Map</b> — multimodal RAG over a restaurant and recipe corpus</summary>

<br>

Capstone for the IBM RAG and Agentic AI Professional Certificate.

- Dual MiniLM and CLIP embedding pipeline with weighted fusion and reranking, built after single-text retrieval missed image-described dishes close to half the time
- Multi-agent recommendation system exposed over a FastMCP server
- ReAct agent loop with a Gradio chat interface
- ChromaDB vector store, 109 food images captioned via vision LLM

**Stack:** LangChain · LangGraph · ChromaDB · FastMCP · watsonx

</details>
